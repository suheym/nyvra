# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Nyvra, please do not publicly disclose it through GitHub Issues.

Instead, please report it privately through GitHub's security reporting features.

When reporting a vulnerability, please include:

- A description of the issue
- Steps to reproduce it
- The potential security impact
- Any relevant screenshots, logs, or proof-of-concept details

Please allow reasonable time for the issue to be reviewed and addressed before publicly disclosing it.

## Scope

Security reports related to authentication, authorization, data isolation, sensitive journal data, API security, dependency vulnerabilities, and accidental secret exposure are especially important.

## Responsible Use

Nyvra handles sensitive mental-wellness information. Please avoid accessing, modifying, or sharing another person's data while testing the application.

Thank you for helping keep Nyvra and its users safe.
